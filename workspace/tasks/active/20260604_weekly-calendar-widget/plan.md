참고 이미지를 기반으로 삼성 캘린더 주간 시간표 위젯을 깔끔하게 재설계한 HTML 프로토타입 제작.

| 항목 | 내용 |
|------|------|
| 날짜 범위 | 오늘(2026-06-04 목) 기준 7일 |

| 오늘 강조 | 파란 원 또는 accent 색상 |
| 스타일 | 깔끔한 라이트 테마, 참고 이미지보다 정제된 느낌 |
